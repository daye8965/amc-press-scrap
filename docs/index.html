스크랩마스터에서 이미지로 저장한 그날 지면(폴더째 가능)
  1. 왼쪽에서 지면을 넘겨 보다가
  2. 기사를 드래그로 오리고 (단이 꺾이면 Shift+드래그로 조각 추가)
  3. 분류·제목·도움말을 적어 스크랩에 담고
  4. 오른쪽 「PDF 만들기」로 저장
