# 스크랩 후보 찾기

스크랩마스터에서 이미지로 저장한 **하루치 지면 폴더**를 읽어서,
병원·의료 관련 기사가 **어느 신문 몇 면에 있는지** 후보 목록을 만들어 주는 Windows 프로그램입니다.

- 신문을 처음부터 넘기는 대신, 표시된 면만 스크랩마스터에서 오리면 됩니다.
- 스크랩 1쪽 목차 형식의 **초안**도 만듭니다. `: 서울아산병원 피부과 ○○○ 교수 도움말` 줄까지 채워 줍니다.
- **설치가 필요 없습니다.** 글자 읽는 엔진(OCR)이 프로그램 안에 들어 있고, 인터넷 없이 동작합니다. 지면이 PC 밖으로 나가지 않습니다.

> 홍보팀 내부 업무 도구입니다. 지면 이미지는 저작권 때문에 이 저장소에 올리지 마세요(`.gitignore`로 막아 두었습니다).

## 내려받기

오른쪽 **Releases**에서 최신 버전의 **`스크랩후보찾기.zip`**을 받아 압축을 풉니다.
프로그램 폴더째 바탕화면 등 원하는 곳에 두고 쓰면 됩니다.

처음 실행할 때 Windows가 「PC 보호」 창을 띄우면 **추가 정보 → 실행**을 누르세요.
서명하지 않은 사내 프로그램이라 나오는 안내입니다.

## 쓰는 법

1. `ScrapFinder.exe`를 더블클릭합니다.
2. **폴더 선택…**으로 그날 지면 이미지 폴더를 고릅니다. 신문별 하위 폴더로 나뉘어 있어도 됩니다.
   지면 폴더를 `ScrapFinder.exe` 아이콘 위에 끌어다 놓으면 바로 시작합니다.
3. **▶ 후보 찾기**를 누릅니다. 처음엔 면당 10~15초가 걸리고, 같은 폴더를 다시 돌리면 몇 초 만에 끝납니다.
4. 끝나면 결과 화면이 열립니다. 결과는 지면 폴더 안 `_스크랩후보` 폴더에 저장됩니다.

| 파일 | 내용 |
|---|---|
| `결과.html` | 왼쪽: 분류별 후보 목록 / 오른쪽: 키워드를 형광펜으로 칠하고 추정 제목에 빨간 테두리를 친 지면 |
| `목차초안.txt` | 스크랩 1쪽 형식의 초안. 복사해서 고쳐 쓰면 됩니다 |
| `결과.json` | 같은 내용의 데이터 (나중에 월별 집계 등에 사용) |

## 키워드 바꾸기

프로그램의 **키워드 편집** 버튼을 누르면 `키워드.txt`가 메모장으로 열립니다.

```
[서울아산병원]          ← 하나만 나와도 후보
서울아산병원
울산의대

[의료/정책 min=3]       ← 한 기사에 3번 이상 나와야 후보 (흔한 단어용)
보건복지부
전공의
```

- 위에 적힌 분류가 우선합니다.
- 띄어쓰기는 무시합니다.
- 5글자 이상 키워드는 OCR 오타도 잡습니다. 예를 들어 `서울야신병원`도 `서울아산병원`으로 찾습니다.

## 알아 둘 점

- **잘 되는 것:** 병원명 찾기와 `○○과 ○○○ 교수` 추출.
  2026-11-19 경향신문 H01면 「뜨거운 물 샤워」 기사를 찾아냈고, 실제 스크랩과 같은 도움말 줄을 만들었습니다.
- **반드시 사람이 확인할 것:**
  - **제목:** 큰 글씨를 따로 한 번 더 읽어 추정합니다. 띄어쓰기가 빠지거나 비어 있을 수 있습니다.
  - **매체·면 번호:** 지면 머리글에서 읽는데, 로고가 그림인 신문(예: 헬스경향)은 비어 있을 수 있습니다.
    이럴 때는 폴더나 파일 이름에 매체명과 면 번호(`A12` 형식)가 들어 있으면 그것을 씁니다.
  - **서울아산병원과 무관한 의료/정책 기사:** 병원명만으로는 판단이 어려워 놓칠 수 있습니다.
    `키워드.txt`의 [의료/정책] 목록을 다듬어 가며 맞춰야 합니다.
- **해상도:** 저장한 이미지의 해상도가 높을수록 정확합니다. 가로 2600픽셀보다 작은 이미지는 자동으로 확대해서 읽습니다.

## 다음 단계 (예정)

후보 기사를 화면에서 드래그로 오리고, 목차·로고·날짜를 붙여 지금 쓰는 형식의 **스크랩 PDF를 바로 출력**하는 기능.

## 개발 메모

| 파일 | 역할 |
|---|---|
| `scrapfinder.py` | 핵심 처리 (OCR → 키워드 → 제목 추정 → 결과). `python scrapfinder.py <폴더>`로 단독 실행 가능 |
| `app.py` | 창 화면 (tkinter) |
| `키워드.txt` | 분류·키워드 목록 |
| `build/smoke_test.py` | 가짜 지면을 그려 서울아산병원 기사·도움말 줄을 찾는지 확인 |
| `.github/workflows/build.yml` | Windows 빌드 서버에서 exe를 만들고 시험한 뒤 zip으로 묶음. `v`로 시작하는 태그를 올리면 Releases에 게시 |

새 버전 배포: 변경을 main에 올린 뒤 `v0.2.0` 같은 태그를 push하면 Releases에 zip이 자동으로 올라갑니다.

개발용 PC에서 직접 돌리려면 Python, `pip install pillow`, [Tesseract](https://github.com/UB-Mannheim/tesseract/wiki)(Korean 데이터 포함)가 필요합니다.
